# Rock-Paper-Scissors-Game
You can play rock, paper, or scissors with this python program. Its automated. 

# Instructions

1. The program outputs this response "Pick one: Rock, Paper, or Scissors: "
2. The user types in the one of the three words.
3. The user's input gets stored into a variable
4. That variable gets checked with if/elif/else statement.
5. The variable that matches the if/elif/else statement prints out the output of that statement.
6. Then the program outputs a question "Do you wanna play again? (y/n): ".
8. If the user types in "y", then it goes back to the the top of the program. If the user types in "n" then the program stops.

# Concepts Learned: 

* While loops
* if/elif/else statements
* the random module
